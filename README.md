🌱 Sobre Green Wings

Green Wings es un videojuego 2D de plataformas creado en equipo utilizando Godot Engine.

El jugador controla a un dragón verde capaz de moverse, saltar, volar y recoger frutas mientras explora el escenario.

El proyecto está inspirado en los clásicos juegos de plataformas, tomando como referencia la esencia de títulos como Mario Bros., pero desarrollando nuestro propio personaje, mundo y mecánicas.

🚧 Actualmente se encuentra en desarrollo y la demo todavía no está terminada.

🐉 El dragón

El protagonista es un pequeño dragón verde creado específicamente para el proyecto.

Entre sus principales habilidades se encuentran:

🏃 Movimiento.
🦘 Salto.
🪽 Vuelo.
🍎 Recogida de frutas.
🌿 Exploración del escenario.

La posibilidad de volar es una de las mecánicas principales y permite explorar el mundo de una manera diferente.

🎮 Desarrollo

El proyecto ha sido desarrollado con Godot Engine, trabajando tanto en la parte visual como en la programación y las mecánicas.

⚙️ Mi aportación

Dentro del equipo, mis principales responsabilidades fueron:

🎮 Crear el proyecto en Godot.
🐉 Crear el personaje principal.
🎞️ Crear las animaciones.
🏃 Implementar el movimiento.
🪽 Implementar la mecánica de vuelo.

Cada integrante aportó diferentes habilidades al desarrollo, combinando programación, diseño, contenido y música para construir el videojuego.

🌿 El resultado es fruto del trabajo conjunto del equipo.
