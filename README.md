🌿 About the Game

Green Wings is a collaborative 2D platformer developed with Godot.

The game follows a small green dragon on an adventure through a colorful world where the player can move, jump, fly and collect fruits while exploring the environment.

The project takes inspiration from classic platform games such as Mario Bros., while developing its own protagonist, visual identity and gameplay elements.

🐉 A small dragon with wings, a world to explore and an adventure waiting to begin.

🐉 The Main Character

The protagonist of Green Wings is a green dragon created specifically for the project.

The character was designed and developed as part of the game's visual and technical development.

🪽 Character abilities

The dragon can:

🏃 Move through the level.
🦘 Jump.
🪽 Fly.
🍎 Collect fruits.
🌿 Explore the environment.
🎮 Interact with the game world.

The flying mechanic is one of the elements that gives the character a distinctive gameplay style compared with a traditional platformer.

🎮 Gameplay

Green Wings follows the basic structure of a 2D platform adventure.

The player controls the dragon and navigates through the level while interacting with the environment and collecting objects.

Core gameplay
             🐉 PLAYER
                 ↓
        ┌────────────────┐
        │   MOVE / JUMP  │
        └───────┬────────┘
                ↓
             🪽 FLY
                ↓
        🌿 EXPLORE LEVEL
                ↓
          🍎 COLLECT FRUIT
                ↓
          🎯 CONTINUE


The project is still being developed, so additional mechanics and gameplay elements may be added in future versions.

🪽 Flying Mechanic

One of the main gameplay elements implemented in the project is the dragon's ability to fly.

The mechanic allows the player to move through the environment in a different way from standard platform movement.

This adds another dimension to level exploration and creates possibilities for areas that can only be reached through flight.

🍎 Collectibles

The dragon can also collect fruits throughout the level.

Collectibles provide an additional gameplay objective and encourage the player to explore the environment rather than simply moving from one point to another.

⚙️ Development with Godot

The game was developed using Godot Engine.

I was responsible for creating the project in Godot and working on several of the technical aspects of the game.

My work included the implementation and organization of the game so that its structure could continue growing as new features were added.

🧩 Scalability & Project Structure

Another part of my contribution was working on the scalability of the Godot project.

The intention was to create a structure that would allow the game to grow without having to rebuild the project from scratch whenever a new mechanic or element was introduced.

This involved considering how different parts of the project could be organized and extended as development progressed.

The goal was to maintain a foundation that could support:
